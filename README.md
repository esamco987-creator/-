# مركز التسويات المحاسبية

أداة ويب بملف واحد (`index.html`) تقرأ ملفات إكسل (xlsx / xls / csv) وتحوّل أوراق التسوية
داخلها إلى إذن تسوية رسمي جاهز للمعاينة والطباعة، مع إمكانية التعديل المباشر قبل الطباعة
(النصوص، الأرقام، الألوان، حجم الخط، وإضافة/حذف صفوف الجدول)، وتبديل صيغة الأرقام بين
العربية والإنجليزية.

## طريقة الاستخدام محليًا
افتح ملف `index.html` مباشرة في المتصفح — لا حاجة لأي تثبيت أو خادم.

## النشر على GitHub Pages
1. أنشئ مستودع (repository) جديد على GitHub وارفع ملف `index.html` (وملف `README.md` هذا اختياري).
2. من إعدادات المستودع: **Settings → Pages**.
3. تحت **Source** اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
4. بعد دقيقة أو اثنتين ستكون الأداة متاحة على رابط من نوع:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

كل شيء يعمل داخل المتصفح فقط (لا يوجد خادم أو قاعدة بيانات)، والملفات التي يرفعها المستخدم
لا تُرسل لأي مكان — تُعالج محليًا في المتصفح فقط.
